## CSS and Responsive Design
The website was styled using an external CSS stylesheet. CSS was used to improve the layout, typography, colors, spacing, borders, shadows, and overall visual appearance. Flexbox was used to structure the page, while hover, focuses, and active state were added to interactive product items. 

Responsive design was implemented using media queries for mobile, tablets, and desktop screen sizes. Relative units such as percentages and rem were used to help the contact adapt to different screen sizes. Cupcake image was also made responsive using srcset and sizes.
